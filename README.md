# JavaFX Puzzle Game

Un juego de puzzle deslizable desarrollado en Java con interfaz gráfica JavaFX. Permite al usuario definir la dimensión del tablero, desordenar las fichas y organizarlas hasta completar el juego.

## 🚀 Características
* **Tablero dinámico:** El usuario elige la dimensión del juego al iniciar.
* **Fichas móviles:** Controles para desplazar las piezas vacías y adyacentes.
* **Función para barajar:** Botón integrado para mezclar el tablero de forma aleatoria.
* **Detección de victoria:** Muestra un mensaje emergente cuando el tablero se ordena correctamente.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Java
* **Interfaz Gráfica:** JavaFX (GridPane, BorderPane, Alert, HBox)
